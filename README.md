## Overview

SKSE64 (Skyrim Script Extender 64-bit) extends the scripting capabilities of Skyrim Special Edition and Anniversary Edition far beyond the vanilla Papyrus limit, providing additional functions for mod authors and serving as the required dependency for thousands of advanced mods including SkyUI, USSEP, and virtually every complex Skyrim mod published in the last decade.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **SKSE64** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Script Extension** | Hundreds of additional Papyrus script functions for mod authors |
| **Required By Thousands** | Dependency for SkyUI, USSEP, and most complex Skyrim SE mods |
| **64-Bit Architecture** | Native 64-bit implementation for Skyrim SE and AE executables |
| **Rapid Updates** | Updated within days of each Skyrim SE patch to restore mod compatibility |
